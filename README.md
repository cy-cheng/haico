# Waymark — HAICO 2026

Waymark helps friends turn travel ideas shared in an existing group chat into an itinerary they can review and revise together. This repository is organized by milestone for Group 4.

| Directory | Contents |
|---|---|
| [`milestone2/`](milestone2/) | Milestone 2 reports, presentation, editable Typst sources, prototype visuals and supporting material |
| [`milestone3/`](milestone3/) | Reserved for the Milestone 3 working system |

## Milestone 2

See the [Milestone 2 README](milestone2/README.md) for deliverables and full build instructions. Run builds from that directory:

```sh
cd milestone2
make
```

On macOS, double-click [`milestone2/render.command`](milestone2/render.command) to build and open the report.
