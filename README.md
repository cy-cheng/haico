# Waymark — HAICO 2026 Milestone 2

Slides for our Milestone 2 proof of concept: Waymark, an AI travel assistant that lives in a group chat (Discord for the demo, LINE later). The design is at <https://claude.ai/artifact/75jXxDxX1EwALYK2eui1Xs>; the earlier standalone prototype was at <https://yiguo12.github.io/waymark-travel-bot/>.

## Build

Requires [Typst](https://typst.app) 0.14 or newer. The fonts are bundled, so no installation is needed:

```sh
typst compile --font-path fonts slides.typ slides.pdf
```

Without these fonts Typst substitutes wider ones, and text spills out of its boxes. Make previews use them too:

- **VS Code (Tinymist):** `.vscode/settings.json` already points Tinymist at `fonts/`.
- **Neovim or any other editor:** install the fonts for your user, e.g. on Linux `cp fonts/*.ttf ~/.local/share/fonts/ && fc-cache -f`.
- **typst.app:** upload the `fonts/` folder with the project.

## Layout

| Path | What it is |
|---|---|
| `slides.typ` | Main deck: sections 3–5 (user flow, role of AI, limitations); includes `front.typ` |
| `front.typ` | Cover and sections 1–2 (motivation, refined goal) |
| `theme.typ`, `visuals.typ` | Shared theme and drawings |
| `assets/screens/ui/` | Discord and web-app screens exported from the Design canvas (`d-` = Discord, `a-` = app); `assets/screens/*.jpg` are the old prototype screenshots |
| `assets/user-flow-en-*.svg` | English user flow and its three close-ups, generated by `tools/make_flow.py` |
| `assets/icons/` | Lucide icons (ISC licence) |
| `fonts/` | Fraunces, Newsreader, IBM Plex Mono (SIL Open Font License; see `fonts/OFL-*.txt`) |
| `open-issues.md` | Design conflicts and open questions to resolve |

To change the user flow, edit the labels in `tools/make_flow.py`, then run `python3 tools/make_flow.py assets`.

The static Fraunces files have their internal family name changed from "Fraunces 72pt" to "Fraunces" to match `theme.typ`.
